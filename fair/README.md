# Осенняя ярмарка — консольный прототип

Проверка правил экономической игры (`Осенняя ярмарка — правила игры.md`) на ботах и вручную. Без зависимостей кроме `pyyaml`.

## Запуск

```
python -m fair play  [--role Повар] [--seed 7] [--verbose]    # играть самому против 9 ботов
python -m fair watch [--seed 7] [--brief]                      # смотреть партию ботов целиком
python -m fair sim   -n 300                                    # сводка по 300 партиям + флаги
python -m fair sim   -n 200 --sweep buyers_per_player=0.7,1.0 --sweep banquet.bonus=0.2,0.3
python -m fair edit  [--port 8765]                             # редактор в браузере
python -m fair web   [--port 8766] [--role Повар] [--seed 7]   # играть против ботов в браузере
```

## Плейтест в браузере (`web`)

То же, что `play`, но кнопками: сбор и готовка с подсказкой, что можно приготовить; стакан заявок, свои заявки и обмен с ботом (видно его склад); на ярмарке — таблица цен продавца, карточка покупателя с максимумами и выгодой, встречная цена, втюхивание, тендер, банкет. Справа — склад, заказы, экономика всех игроков, рецепты с себестоимостью. Журнал партии со скрываемыми сделками ботов. Новая партия — с выбором роли, сида и числа игроков; конфиг перечитывается с диска, так что правки из редактора сразу в игре.

## Редактор (`edit`)

Локальная страница на `127.0.0.1`: роли, сырьё, блюда, все числа баланса, архетипы ботов и пороги флагов. Переименование сырья или роли доходит до рецептов и профилей. У блюда видно стоимость сырья и маржу, у каждого поля — что было в файле.

Справа прогон ботов на текущих правках (даже несохранённых): плитки метрик, роли и архетипы с победами против честной доли, флаги. Дельты считаются от эталона — первого прогона или закреплённого.

«Сохранить» (Ctrl+S) сначала проверяет, что контент сходится и партия доигрывается, затем пишет `config.yaml`; прошлая версия остаётся в `config.yaml.bak`. Комментарии сохраняются через `ruamel.yaml` (есть в `requirements-dev.txt`); без него файл запишется через pyyaml без комментариев.

Общие ключи: `--set ключ=значение` (сколько угодно), `--players 12`, `--mix balanced,pusher`, `--config свой.yaml`.
`sim --csv out.csv` дописывает в CSV строку на каждого игрока каждой партии (для своих графиков), `--report` со `--sweep` — полная сводка по каждому сочетанию.

## Где что

| Файл | Что |
|---|---|
| `config.yaml` | все числа правил, сырьё, блюда, роли, параметры ботов, пороги флагов |
| `engine.py` | правила и ход партии: работа, рынок, ярмарка, остановки, втюхивание, тендер, банкет, подсчёт |
| `bots.py` | боты; поведение задают архетипы (`bots.archetypes`) поверх `bots.defaults` |
| `human.py` | консольный игрок (тот же интерфейс, что у ботов) |
| `stats.py` | метрики, сводка, флаги «экономика рушится» |
| `editor.py`, `editor.html` | редактор конфига в браузере (`python -m fair edit`) |
| `play.py`, `play.html` | плейтест в браузере (`python -m fair web`): веб-игрок и сервер |

## Упрощения относительно правил

- Таймеров нет, всё пошагово. Тендер — раунды понижения, пока никто не снизит.
- Голосовой торг на рынке заменён стаканом заявок: боты выставляют «куплю/продам» по своей оценке и сводятся между собой; человек исполняет заявки, выставляет свои или предлагает боту обмен (бот соглашается, если ему выгодно).
- Боты оценивают спрос на сырьё по нуждам всех ботов (заменяет разговоры на рынке).
- Лук и зелень заменены: лук → соль; зелень → соль (суп, паштет) и сахар (маринованные грибы, картофельный салат).
- Цены ботов задаются долями диапазонов правил (`ask_q`, `push_q` …), поэтому при правке `buyer.max_range` / `buyer.weakness_range` боты подстраиваются.

## Тесты

`python -m pytest tests/test_fair.py` — детерминизм по сиду, сходимость денег до монеты, запрет цены выше максимума, полная партия скриптового человека, страж баланса (300 партий при 6, 10, 12 игроках — ни одного флага).
