# Предвечерний чек-лист

## Ноутбук
- [ ] Вход выполнен, экран не заблокирован, сон и автоблокировка выключены, на зарядке.
- [ ] IP закреплён в роутере по MAC-адресу; адрес в QR совпадает.
- [ ] Порт сервера открыт в `ufw` (если включён: `sudo ufw allow 8000/tcp`); роутер не изолирует клиентов (проверено с телефона).
- [ ] Профиль Firefox `pumpkin` с разрешённым автовоспроизведением (`start.sh` создаёт его сам); звук HDMI выбран в настройках звука Ubuntu.
- [ ] `/check` без красных пунктов, заглушки осознанно оставлены или заменены.

## Охота за семечками
- [ ] Лист `/seeds/print` распечатан в цвете, семечки вырезаны и спрятаны (радужную — похитрее).
- [ ] В шпаргалке (или в `content/seeds.yaml`, поле `place`) записано, где какая: после раунда собрать ненайденные.
- [ ] Коды после печати не менялись (`tools/make_seeds.py --force` перезапишет их).

## Бомба
- [ ] Темы в `content/bomb.yaml` вычитаны (на ТВ видна одна строка крупно), хотя бы три.
- [ ] Порядок хода на `/host` расставлен так, чтобы соседи по кругу сидели рядом (кто кому «передаёт»).

## Устройства гостей и ведущего
- [ ] iPad: автоблокировка «Никогда», яркость, страница `/carve` открыта.
- [ ] Телефон ведущего: автоблокировка «Никогда», страница `/host` открыта.
- [ ] Android-гости: вибрация не отключена (по желанию).

## Полезные команды (с ПК)
- `tools/deploy.sh <хост>` или `tools\deploy.ps1 <хост>` — перенести проект.
- `tools/remote_check.sh <хост>` — проверки без браузера (со снимком вебки).
- `tools/remote.sh <хост> status|log|restart|stop` (на Windows `tools\remote.ps1`).
- Если окно Firefox по ssh не открылось (Wayland/X11), один раз запустить `./start.sh` руками на ноутбуке.

## Ассеты и деплой
- Настоящие ассеты (Rive, видео, звуки, рамка, аватары, наклейки) кладите на ПК в `assets/` и коммитьте: `tools/deploy.sh` синхронизирует проект с удалением лишнего и затрёт файлы, положенные прямо на ноутбук.
- После замены ассетов `/check` должен показать меньше заглушек.
- Озвучка фактов: `content/audio/fNNN.mp3`, затем `python tools/make_lipsync.py`, предпросмотр — `/tools/lipsync-preview`.
