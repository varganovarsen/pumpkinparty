# Формат контента

Контент это текстовые файлы в `content/`, редактируемые вручную в любом редакторе. Кодировка UTF-8. Базы данных и админки для контента нет.

## content/facts.yaml

Один файл для головы-тыквы и для раунда 4 квиза.

```yaml
- id: f001                       # уникальный, нижний регистр, без пробелов
  text: "Тыква — ягода. Ботаники называют её гарбузом."   # до 220 символов (влезает в пузырь)
  audio: f001.mp3                # файл в content/audio/ (может отсутствовать, тогда голова молчит и в громком режиме)
  quiz:                          # необязательный блок: факт участвует в раунде 4
    question: "Кто по ботанической классификации тыква: овощ, фрукт или ягода?"
    answer: "Ягода (гарбуз)"     # эталонный ответ для сверки ведущим
```

Правила:
- 35-40 фактов, минимум 12-15 с блоком `quiz`.
- Показанным факт считается, когда пузырь появился на `/tv` (в тихом режиме тоже).
- Раунд 4 берёт вопросы только из показанных фактов с блоком `quiz`, случайно, без повторов. Если их меньше пяти, раунд идёт с тем количеством, что есть.
- Рядом с каждым `fN.mp3` лежит `fN.lipsync.json` (создаётся скриптом `tools/make_lipsync.py`).

## content/quiz.yaml

Раунды 1-3 по 10 вопросов, раунд 4 собирается из фактов (см. выше) и в этом файле не описывается.

```yaml
rounds:
  - id: r1
    title: "Сельское хозяйство"
    questions:
      - id: r1q01
        text: "Какая температура почвы нужна для высадки рассады тыквы?"
        options: ["Около 5 °C", "Около 8 °C", "Не ниже 12-14 °C", "Не ниже 25 °C"]   # ровно 4
        correct: 2               # индекс правильного ответа, с нуля
        explain: "Тыква теплолюбива, ниже 12 °C рост останавливается."   # необязательно, показывается на ТВ после ответа
  - id: r2
    title: "Угадай сорт"
    questions:
      - id: r2q01
        image: sorts/butternut.jpg    # файл в content/images/, показывается на ТВ, на телефонах только кнопки
        text: "Что это за сорт?"
        options: ["Мускатная", "Баттернат", "Хоккайдо", "Спагетти"]
        correct: 1
  - id: r3
    title: "Тыква в культуре"
    questions: [ ... ]
```

Правила:
- Ровно 4 варианта, один правильный. Раунды 1-3 по 10 вопросов.
- В раунде 2 у каждого вопроса есть `image`; нужно 10 разных сортов.
- Фото сортов: Wikimedia Commons (проверить лицензию) или собственные; хранить в `content/images/sorts/`, ширина до 1600 px.

## content/seeds.yaml

Коды для охоты за семечками (модуль 09). Создаётся `python tools/make_seeds.py`, можно править руками.

```yaml
- {code: "4817", kind: regular, place: "под вазой в прихожей"}
- {code: "0170", kind: rainbow, place: ""}
```

- `code` — цифры **в кавычках** (иначе YAML съест ведущий ноль), уникальные, одной длины (телефон отправляет код по последней цифре).
- `kind` — `regular`, `golden` или `rainbow` (радужная одна).
- `place` — где спрятана: видно только ведущему (`/host` и шпаргалка при печати). Удобно заполнить после того, как спрятали.
- Если семечки уже распечатаны, коды не менять: напечатанные перестанут совпадать.

## Проверка (`tools/check_content.py`)

Результат виден на странице `/check`. Скрипт ловит:
- нарушения структуры и дубликаты `id`;
- отсутствующие файлы `audio`, `lipsync.json`, `image`;
- тексты длиннее лимита пузыря;
- вопросы не с 4 вариантами или с `correct` вне диапазона;
- число фактов с `quiz` меньше 12 (предупреждение, не ошибка).
