# Модуль 09. Охота за семечками

Дополнение к спеке по запросу заказчика (16.10.2026). Отдельный раунд-сцена `seeds` («Охота за семечками»),
по рекомендуемому порядку — после игры «Падающие тыквы».

## Идея

Ведущий заранее прячет по комнате бумажные семечки с кодом из цифр. По старту ведущего гости ищут их 5 минут
и вводят коды на телефоне. Каждую семечку засчитывают **только первому**, кто ввёл её код. Очки идут в общий зачёт.

Цифры вместо QR: код можно написать мелко на чём угодно и спрятать хитрее, камеру открывать не нужно.

## Семечки

- Три вида: обычная (+30), золотая (+100), одна радужная мегасемка (+300). Очки и длительность — `config.yaml`, раздел `seeds`.
- Коды — `content/seeds.yaml` (формат в CONTENT-FORMAT.md). Генератор: `python tools/make_seeds.py`
  (по умолчанию 20 обычных, 5 золотых, 1 радужная; 4 цифры, коды отличаются минимум двумя цифрами).
- Лист для печати: `/seeds/print` (ссылка в панели сцены на `/host`): карточки-семечки в цвете под вырезку
  и вторая страница — шпаргалка ведущему (код, вид, где спрятана, отметка).

## Ход раунда

1. Ведущий включает сцену. ТВ показывает правила, телефоны — правила и «ждём старта».
2. «Старт» → отсчёт 3-2-1 → поиски `minutes` минут. Ведущий может добавить или убавить минуту и закончить досрочно.
3. Телефон: цифровая клавиатура, код уходит сам после последней цифры. Ответы: находка (анимация, звук, вибрация),
   «Нет такой семечки», «Эту уже нашли: Имя», «Эта семечка уже твоя».
4. После `wrong_limit` неверных кодов подряд — пауза `cooldown_seconds`: подбор наугад не окупается.
5. ТВ: таймер, счётчики найденных по видам, рейтинг охоты, лента находок; о каждой находке — плашка, о радужной — на весь экран.
6. Конец по времени, досрочно или когда найдены все. ТВ показывает итоги и сколько семечек не нашли.

## Правила

- Ведущий не ищет (`host_can_play: false`): он прятал. Ведущий вне зачёта, если и найдёт, очков не получит.
- Очки начисляются в момент находки (ledger, `source = seeds`, `ref` = код) и видны в общем рейтинге отдельной строкой «Семечки».
- Повторный раунд — только через аварийный сброс (очки за семечки удаляются).
- Во время поисков сцена «живая»: уход из неё требует подтверждения.
