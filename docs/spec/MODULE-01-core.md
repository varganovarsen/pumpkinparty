# Модуль 01. Ядро

Этап: дни 1-3. Зависимости: нет. Читать вместе с `SPEC.md` разделы 3, 6-11.

## Что входит

1. Сервер FastAPI, WebSocket, SQLite, раздача статики, запуск одной командой.
2. Состояние вечера и журнал начислений (ledger), хранятся на диске.
3. Вход игрока по QR, профиль (имя, аватар-тыква или фото), токен.
4. Машина сцен и страницы `/tv`, `/host`, `/check`, `/` (каркас).
5. Устойчивость: восстановление, резервные копии, аварийные кнопки, журнал событий.
6. Заглушки для ассетов.

## Сервер и состояние

- Один процесс, одно состояние в памяти + запись в SQLite после каждого значимого события.
- При старте сервер поднимает состояние из базы: текущая сцена, игроки, очки, фаза квиза, показанные факты, фото.
- Резервная копия `data/pumpkin.db` и списка файлов каждые 5 минут в `data/backups/<timestamp>/` (хранить последние 12).
- `start.sh` / `start.bat`: проверка Python и зависимостей, запуск сервера. `start.sh` дополнительно запускает Firefox: `firefox --kiosk -P pumpkin http://localhost:8000/tv` (профиль `pumpkin` с `media.autoplay.default = 0`; если окно открыть не удалось, это не ошибка, скрипт печатает подсказку запустить вручную).
- Адрес для QR: `public_host` из конфига, иначе автоопределение IP локальной сети.

## Профили

- Экран входа: имя (1-20 символов, уникальное без учёта регистра) + выбор профиля.
- Аватар-тыква: сетка из `assets/avatars/pumpkin-1…8.png`; один аватар не может занять двое (занятые затемнены). Для фото-профиля аватар-тыква не занимается.
- Фото-профиль: выбор «Снять» (`capture`) или «Из галереи» (`accept="image/*"` без `capture`), HEIC принимается, круглая обрезка, сервер приводит к JPEG/PNG 256×256. Редактор общий с селфи (модуль 03), здесь доступна обрезка, фильтр и наклейки опционально.
- Токен в `localStorage`. Повторный вход по тому же токену восстанавливает игрока. Если токена нет, а имя занято, предложить «Это я?» только если игрок отключён (подтверждение без пароля, доверенный круг).
- Профиль можно изменить в любой момент на вкладке «Профиль» (имя менять нельзя после первого входа, [по умолчанию]).

## Сцены

- Сервер хранит `scene` и `scene_payload`. Переход только по команде ведущего (`cmd: set_scene`), кроме явных автоматических случаев из модулей.
- Выход из сцены с живой фазой (квиз, игра, голосование) требует подтверждения на `/host`.
- Для каждой сцены `/tv` загружает свой модуль лениво.

## Интерфейс игрока (каркас)

- В `ambient` внизу вкладки: «Фото», «Альбом», «Факты», «Профиль». Сверху строка статуса: аватар, имя, очки (очки скрыты, если включено скрытие общего рейтинга).
- При запуске сцены с участием (квиз, игра, голосование за резьбу) экран переключается на полноэкранный режим без вкладок. После сцены возвращаются вкладки.
- Сцены без участия (`timer`, `slideshow`, `final_photo`, `rating_reveal`, `download`) ничего не переключают, сверху тонкая плашка (например «Перерыв: 7:42», «Идёт слайд-шоу»).
- Если гость в середине редактирования селфи, а запустилась сцена с участием: экран переключается, черновик остаётся на телефоне, вкладка «Фото» предлагает «Продолжить».
- Потеря связи: сверху красная полоска «Нет связи», переподключение автоматическое.
- Вибрация (Android): `navigator.vibrate` в начале вопроса, при предупреждении и в конце времени; на iOS её нет, всё дублируется визуально.

## Панель ведущего `/host` (каркас)

- Мобильная вёрстка: крупная кнопка «Следующий шаг» (контекстная) + ряд переключателей сцен + раздел текущей сцены.
- Постоянный блок: список игроков (имя, аватар, связь, очки), `host_in_scoring`, режим головы (тихий/громкий), «Тихий режим» одним нажатием, «Позвать голову сейчас».
- Журнал событий (последние 50 строк, фильтр по игроку).
- Аварийный раздел: «Перезагрузить сцену», «Пропустить вопрос», «Исправить очки игрока» (± число + комментарий, пишется в ledger), «Сбросить вечер» (двойное подтверждение, перед сбросом автоматически копия `data/` в `data/backups/before_reset_<ts>/`).
- Страница `/check` (раздел «Проверки»): адрес и QR, число подключённых телефонов, тест звука на `/tv`, тест вебки (кадр показывается ведущему), свободное место на диске, наличие всех файлов контента и ассетов (список заглушек), результат `check_content`, версия Python, тип графической сессии (`$XDG_SESSION_TYPE`).

## `/tv` (каркас)

- Только с localhost. При загрузке запрашивает текущее состояние и показывает нужную сцену; перезагрузка страницы ничего не теряет.
- Кнопка «Запустить вечер» на стартовом экране (разрешает звук; если автовоспроизведение уже разрешено профилем Firefox, экран пропускается).
- Сцены-заглушки на этом этапе: каждая показывает название и состояние.

## Приёмка

- [ ] `start.sh` на ноутбуке поднимает сервер и открывает `/tv`; `start.bat` поднимает сервер на ПК.
- [ ] Телефон по QR попадает на вход; имя и аватар сохраняются; перезагрузка страницы возвращает игрока.
- [ ] Дубль имени отклоняется; занятый аватар недоступен.
- [ ] Переключение сцен с `/host` мгновенно меняет `/tv` и интерфейс телефонов.
- [ ] Перезапуск сервера посреди сцены: `/tv`, `/host` и телефоны возвращаются без потери очков и игроков.
- [ ] Ручная правка очков меняет итог и пишется в журнал.
- [ ] «Сбросить вечер» делает копию и очищает состояние.
- [ ] `/check` показывает заглушки и все красные пункты.
- [ ] `/tv` недоступна с другого устройства сети.
- [ ] Прогон `tools/simulator.py` (когда появится) с 8 игроками не роняет сервер.
