# Модуль 04. Голова-тыква, факты и ambient

Этап: день 12 (заглушки раньше, с этапа 1). Зависимости: модуль 01. Читать вместе с `CONTENT-FORMAT.md`.

## Ambient (главный экран)

- Фон: `assets/video/ambient.webm` (камин или листопад), зацикленное воспроизведение, без звука, на весь экран. Шов цикла не должен быть заметен (длинный ролик или плавное перекрытие, готовит заказчик).
- Лёгкий режим: переключатель на `/host`, вместо видео статичная `assets/img/ambient-light.jpg` и лёгкий листопад на canvas/CSS. Нужен как запасной вариант, если ноутбук не тянет.
- Постоянно на экране: небольшой QR-код в нижнем углу и под ним текстом адрес. Рейтинга нет.
- Поверх фона: голова-тыква (ниже), карточка новых фото (модуль 03).
- Звука в ambient нет, кроме озвучки головы в громком режиме и сигнала случайного кадра.
- Нагрузка: на этапе 1 замерить загрузку процессора ноутбука с видео и всеми оверлеями. Цель: не выше ~50%, без пропуска кадров.

## Голова-тыква

Выглядывает из правого нижнего угла, пузырь с текстом занимает примерно четверть экрана, вход и выход плавные. Работает **только в сцене `ambient`**.

### Когда появляется

- По таймеру: каждые 6 минут ±1 минута (случайный разброс), но не раньше чем через 3 минуты после окончания любой другой сцены. Если срок наступил вне ambient, ждёт возврата и этих 3 минут.
- Кнопка «Позвать сейчас» на `/host`.
- Игроки голову вызвать не могут.
- На `/host`: интервал (по умолчанию 6 минут), вкл/выкл, «Пропустить текущий факт».

### Выбор факта

- Случайный из ещё не показанных; когда показаны все, цикл начинается заново.
- Факт отмечается показанным, когда пузырь появился на `/tv` (в тихом режиме тоже). Эта отметка используется раундом 4.

### Режимы

- **Тихий (по умолчанию при старте):** короткий звук оповещения (`sfx/fact-notify.mp3`) и текст в пузыре. Пузырь висит ~20-25 секунд.
- **Громкий:** звук оповещения, текст и озвучка mp3. Пузырь висит до конца аудио + 3 секунды.
- Переключатель режима на `/host`, плюс «Тихий режим» одним нажатием.
- Если факт уже на экране в тихом режиме, на `/host` появляется кнопка «Озвучить»: проигрывает озвучку с начала и продлевает показ до конца речи + 3 секунды.
- Нет mp3 у факта: в громком режиме показывается только текст.

### Список фактов на телефонах (вкладка «Факты»)

- Показанные факты открыты полным текстом, непоказанные скрыты как «?» (виден только порядковый номер). Во время раунда 4 вкладка недоступна («Недоступно во время раунда»).

## Контракт с Rive (`assets/rive/head.riv`)

State machine `HeadSM`. Заказчик делает ассет, код только управляет входами.

| Вход | Тип | Назначение |
|---|---|---|
| `appear` | trigger | появление |
| `leave` | trigger | уход |
| `talk` | bool | `true` на время речи (поза, наклон, моргание) |
| `mouth` | number 0-100 | открытость рта (основной способ липсинка) |
| `viseme` | number 0-4 | форма рта: 0 закрыт, 1 слегка открыт, 2 широко («а»), 3 кружок («о/у»), 4 растянут («э/и»); 5 зарезервирован. Необязателен |
| `mood` | number | вариант эмоции. Необязателен |

Требования к ассету: отсутствие любого необязательного входа не ломает работу (код проверяет наличие входа). Мимика (`mood`) и рот (`mouth`, `viseme`) должны быть на **разных слоях** state machine, иначе высокая улыбка гасит рот. Заглушка: простая анимация, пока нет `.riv`.

## Липсинк

- Данные считаются **заранее**, живого анализа звука нет. Скрипт `tools/make_lipsync.py` (numpy/scipy) для каждого `content/audio/<id>.mp3` создаёт `<id>.lipsync.json`:
  - 30 кадров в секунду; сглаженная огибающая громкости превращается в `mouth` 0-100;
  - «светлость» звука (спектральный центроид) выбирает `viseme` 0-4;
  - настройки скрипта: сглаживание, порог тишины, границы форм (параметры командной строки).
- Формат файла: `{"fps": 30, "frames": [{"t": 0.00, "mouth": 12, "viseme": 1}, …]}`.
- Страница `/tv` читает `audio.currentTime` в `requestAnimationFrame`, находит кадр и подаёт значения в Rive. Нет JSON: `talk = true` и зацикленное движение рта на время аудио.
- Предпросмотр: страница `/tools/lipsync-preview` показывает волну, значения `mouth` и `viseme` по времени и проигрывает аудио, чтобы можно было подкрутить параметры, не запуская вечер.
- Озвучка: сервис синтеза выбирает заказчик позже, формат mp3 (имя `content/audio/<id>.mp3`).

## Приёмка

- [ ] Ambient: видео зациклено, QR и адрес в углу, лёгкий режим включается с `/host`.
- [ ] Голова появляется по таймеру с разбросом, не ближе чем через 3 минуты после другой сцены, не появляется вне ambient.
- [ ] «Позвать сейчас», «Пропустить», интервал и вкл/выкл работают.
- [ ] Тихий режим: звук оповещения и текст, голос не звучит; «Озвучить» проигрывает с начала и продлевает показ.
- [ ] Громкий режим: озвучка, пузырь держится до конца аудио + 3 секунды.
- [ ] Факты не повторяются, пока не показаны все.
- [ ] Вкладка «Факты»: показанные открыты, остальные «?»; недоступна в раунде 4.
- [ ] Липсинк: значения из JSON совпадают со звуком, при отсутствии JSON работает запасная анимация.
- [ ] Без `head.riv` (заглушка) и без необязательных входов ничего не падает.
- [ ] Замер нагрузки с видео и Rive выполнен и записан в `docs/DECISIONS.md`.
