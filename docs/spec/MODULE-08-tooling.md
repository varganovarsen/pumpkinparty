# Модуль 08. Инструменты: симулятор, проверки, деплой, репетиция

Этапы: делается вместе с этапами 1-3 и 6-8, дополняется по мере появления модулей.

## Симулятор (`tools/simulator.py`)

- Поднимает 8 виртуальных игроков по WebSocket (как настоящие телефоны): подключение, профиль, ответы в квизе (разная скорость и точность), игра, голосование за резьбу, обрывы связи и возвраты.
- **Перемотка времени:** коэффициент ускорения (например минута ответа сжимается до секунд). Ускорение работает на стороне сервера и симулятора через общий источник времени (`clock`), не через `sleep`-хаки: серверный код берёт время только из `clock`.
- Сценарий «весь вечер»: ambient, квиз 4 раунда, игра, голосование за резьбу (с готовыми тестовыми тыквами), рейтинг, финал. Проверка итоговых сумм очков по известным ответам.
- Запуск: `python tools/simulator.py --players 8 --speed 30 --scenario evening`. Результат: отчёт с расхождениями (ожидаемые и фактические очки, пропущенные события).
- Симулятор запускается на Windows и на ноутбуке.

## Деплой и удалённая проверка (ssh)

- `tools/deploy.ps1` (Windows) и/или `tools/deploy.sh`: синхронизация проекта с ПК на ноутбук по ssh (rsync/scp), исключая `data/` и `.git`. Один параметр: имя хоста ssh.
- `tools/remote_check.sh`: по ssh на ноутбуке запускает `/check`-проверки без браузера: версия Python и зависимости, права на `/dev/video0`, снимок с вебки, открыт ли порт, `$XDG_SESSION_TYPE`, свободное место, все файлы контента и ассетов.
- Удалённые команды: смотреть журнал сервера, перезапустить процесс.
- Запуск окна Firefox по ssh может не получиться (зависит от графической сессии, X11 или Wayland); в этом случае `start.sh` запускается один раз руками на ноутбуке. Скрипты должны работать при любом типе сессии.

- [ ] Вход выполнен, экран не заблокирован, сон и автоблокировка выключены, на зарядке.
- [ ] IP закреплён в роутере по MAC-адресу; адрес в QR совпадает.
- [ ] Порт сервера открыт в `ufw` (если включён); роутер не изолирует клиентов (проверено с телефона).
- [ ] Профиль Firefox `pumpkin` с разрешённым автовоспроизведением; звук HDMI выбран в настройках звука Ubuntu.
- [ ] `/check` без красных пунктов, заглушки осознанно оставлены или заменены.

Устройства гостей и ведущего:
- [ ] iPad: автоблокировка «Никогда», яркость, страница `/carve` открыта.
- [ ] Телефон ведущего: автоблокировка «Никогда», страница `/host` открыта.
- [ ] Android-гости: вибрация не отключена (по желанию).

## Репетиция (дни 13-14)

- Полный прогон на ноутбуке с реальными телефонами (минимум 2-3 человека) и iPad. Новых функций нет, только исправления.
- Замер нагрузки процессора и частоты кадров на `/tv` с видео, головой и аллеей.
- Проверка перезапуска сервера посреди сцены.
- Проверка звука, вебки и случайных кадров в реальной комнате.
